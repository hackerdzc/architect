# 1級建築士製図試験　記述練習

GitHub Pages で配信する静的ページ。

| ファイル | 役割 |
|---|---|
| `index.html` | 骨組みだけ。本文は持たない |
| `style.css` | 画面・モバイル・印刷（A4）のスタイル |
| `app.js` | `questions.json` を読んで描画し、隠す／検索／印刷などを担当 |
| `questions.json` | **設問データ。編集するのはここだけ** |

## 設問の追加・修正

`questions.json` の `cats[].questions[].rows[]` に1件足すだけ。タブの件数は自動で数え直される。

```json
{
  "kir":  "切り口（左に出る短い問い）",
  "t":    "対象は、",
  "p":    "目的に配慮して、",
  "j":    "実施内容とした。",
  "src":  "TS",
  "perf": "安全性"
}
```

- `perf` … その目的の**性能語**。目的の空欄を1回タップしたときに出るヒント。
  手で書かず、行を足したあとに `python tools/add_perf.py` を実行して付ける。
  未知の目的があるとエラーで止まり、`tools/add_perf.py` のどこに足すか教えてくれる。

- `src` … 出典タグ
  | 値 | 表示 | 意味 |
  |---|---|---|
  | `"T"` | T | TAC |
  | `"S"` | S | 総合 |
  | `"TS"` | T·S | 両校一致 |
  | `"gen"` | 般 | 一般論点。**「般」ボタンで一括非表示にできる** |
  | `"kizon"` | 既 | 既存部との配慮（今年の新ヒント対応）。般を隠しても残る |

  講義でその論点が出てきたら `"gen"` → `"T"` / `"S"` に書き換えると、般を隠したときも残るようになる。
- `t` `p` `j` の中で使える記法
  - `<b>…</b>` … 太字（キーワード）
  - `#…#` … 赤い数字。例 `厚さ #200# のRCスラブ` → 厚さ **200**（赤）のRCスラブ

設問（`questions[]`）を足すときは `nm`（設問名）と `f`（出題頻度）も指定する。
`f` は `"1"` で薄いグレー、`"般"` で緑の「般」、`"既"` で茶色の「既」、それ以外は赤い数字。

## 目的の空欄は3段階

これがこのツールの主目的。目的の点線をタップすると

```
空欄 → 性能語だけ（例：安全性） → 全文 → 空欄
```

一覧から1語選ぶ練習になるようにしている。対象・実施内容は従来どおり2段階。
印刷ではヒントは出ない（空欄のまま）。

## 性能語一覧

語ごとに、いま表示している分類での該当行数が出る。`0` の語は「一覧にはあるが原本にまだ出ていない語」。
その分類で使っているのに一覧の分類が違う語は、下に「他分類」としてまとめて出る。

## 「般」ボタン

出典が `"gen"` の行をまとめて隠す。タブの件数も隠した状態に合わせて数え直される。
両校の資料に載っている論点だけで練習したいときに使う。データは消えない。

## ローカルで確認する

`index.html` をダブルクリックで開くと、ブラウザの制限で `questions.json` を読めない。
このフォルダで簡易サーバを立てる。

```
python -m http.server
```

→ http://localhost:8000/ を開く。GitHub Pages 上では普通に動く。
