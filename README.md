# 1級建築士製図試験　記述練習

GitHub Pages で配信する静的ページ。

| ファイル | 役割 |
|---|---|
| `index.html` | 骨組みだけ。本文は持たない |
| `style.css` | 画面・モバイル・印刷（A4）のスタイル |
| `app.js` | `questions.json` を読んで描画し、隠す／検索／印刷などを担当 |
| `questions.json` | **設問データ。編集するのはここだけ** |

## 画面の作り

分類の切替はスクロール位置に関係なくできる。

| 画面幅 | 分類タブ | ツール（検索・隠す・マーカーなど） |
|---|---|---|
| 1080px 以上 | 左に固定するサイドバー。常に見えている | サイドバーの中。キー操作の一覧もここ |
| 1080px 未満 | 上に貼り付く1行。常に見えている | その下の1行。下スクロール中だけ消え、上に戻すと出る |

ツールの行は絶対配置にしてあり、消えても高さが動かない（本文が飛ばない）。
そのぶんの余白は `app.js` が実測して `--barh` に入れている。

スマホでは1行が縦に積まれるので、切り口を分類色のラベルにして
「ここから次の記述」が見えるようにしている。設問名の下線も分類色。
「すべて」表示では節ごとに `--cat` を差し替えるので、分類の変わり目が色で分かる。

隠せる枠は**目的と実施内容の2つ**。ツール列は
`目的／実施内容／般` `全表示` `マーカー A− A＋` `A4で印刷` の4かたまりで、
PC では左サイドバーに縦に積まれる。

## 設問の追加・修正

`questions.json` の `cats[].questions[].rows[]` に1件足すだけ。タブの件数は自動で数え直される。

```json
{
  "kir":  "切り口（左に出る短い問い）",
  "t":    "対象は、",
  "p":    "目的に配慮して、",
  "j":    "実施内容とした。",
  "src":  "TS",
  "perf": "安全性"
}
```

- `perf` … その目的の**性能語**。目的の空欄を1回タップしたときに出るヒント。
  手で書かず、行を足したあとに `python tools/add_perf.py` を実行して付ける。
  未知の目的があるとエラーで止まり、`tools/add_perf.py` のどこに足すか教えてくれる。

- `src` … 出典タグ
  | 値 | 表示 | 意味 |
  |---|---|---|
  | `"T"` | T | TAC |
  | `"S"` | S | 総合 |
  | `"TS"` | T·S | 両校一致 |
  | `"N"` | 日 | 日建。T・Sと解き方が分かれる論点だけ入れる |
  | `"gen"` | 般 | 一般論点。**「般」ボタンで一括非表示にできる** |
  | `"kizon"` | 既 | 既存部との配慮（今年の新ヒント対応）。般を隠しても残る |

  講義でその論点が出てきたら `"gen"` → `"T"` / `"S"` に書き換えると、般を隠したときも残るようになる。
- `t` `p` `j` の中で使える記法
  - `<b>…</b>` … 太字（キーワード）
  - `#…#` … 赤い数字。例 `厚さ #200# のRCスラブ` → 厚さ **200**（赤）のRCスラブ

設問（`questions[]`）を足すときは `nm`（設問名）と `f`（出題頻度）も指定する。
`f` は `"1"` で薄いグレー、`"般"` で緑の「般」、`"既"` で茶色の「既」、それ以外は赤い数字。

## 目的の空欄は3段階

これがこのツールの主目的。目的の点線をタップすると

```
空欄 → 性能語だけ（例：安全性） → 全文 → 空欄
```

一覧から1語選ぶ練習になるようにしている。実施内容は2段階。
印刷ではヒントは出ない（空欄のまま）。

## 空欄の開き方

開く単位は**枠ではなく1文**。目的と実施内容を同時に隠していても、
どこを押しても・全表示でも・カーソルを置いても、その文は一度に全部出る。

| やり方 | 効き方 |
|---|---|
| 本文をクリック／タップ | その文を開く・閉じる。設問名なら設問ごと |
| 空欄にカーソルを置く（マウスのみ） | 置いている間だけその文が出る。0.12秒待つのは、通りすがりで答が流れないため |
| `全表示` ボタン | 押すたびに固定で全部出す・戻す |
| <kbd>0</kbd> を押す／左ボタンを本文で長押し | 押している間だけ全部出す。離すと**押す前の状態**に戻るので、固定した全表示を巻き添えにしない |

カーソルと長押しは `pointerType` を見て**マウスのときだけ**動かす。
`(hover:hover)` は環境によって `false` を返すことがあり、それだと取りこぼす。
長押しは 0.3 秒。ふつうのクリックとぶつからないよう、
しきい値を超えたときだけ直後の `click` を1回捨てる。

## 性能語一覧

語ごとに、いま表示している分類での該当行数が出る。`0` の語は「一覧にはあるが原本にまだ出ていない語」。
その分類で使っているのに一覧の分類が違う語は、下に「他分類」としてまとめて出る。

## 「般」ボタン

出典が `"gen"` の行をまとめて隠す。タブの件数も隠した状態に合わせて数え直される。
両校の資料に載っている論点だけで練習したいときに使う。データは消えない。

## ローカルで確認する

`index.html` をダブルクリックで開くと、ブラウザの制限で `questions.json` を読めない。
このフォルダで簡易サーバを立てる。

```
python -m http.server
```

→ http://localhost:8000/ を開く。GitHub Pages 上では普通に動く。
