| ファイル | 役割 |
|---|---|
| `index.html` | 骨組みだけ。本文は持たない |
| `style.css` | 画面・モバイル・印刷（A4）のスタイル |

## 設問の追加・修正

`questions.json` の `cats[].questions[].rows[]` に1件足すだけ。タブの件数は自動で数え直される。

```json
{
  "kir": "切り口（左に出る短い問い）",
  "t":   "対象は、",
  "p":   "目的に配慮して、",
  "j":   "実施内容とした。",
  "src": "TS"
}
```

- `src` … `"T"`＝TAC / `"S"`＝総合 / `"TS"`＝両校一致 / `"gen"`＝一般論点
- `t` `p` `j` の中で使える記法
  - `<b>…</b>` … 太字（キーワード）
  - `#…#` … 赤い数字。例 `厚さ #200# のRCスラブ` → 厚さ **200**（赤）のRCスラブ

設問（`questions[]`）を足すときは `nm`（設問名）と `f`（出題頻度）も指定する。
`f` は `"1"` で薄いグレー表示、`"般"` で緑の「般」表示、それ以外は赤い数字。

## ローカルで確認する

`index.html` をダブルクリックで開くと、ブラウザの制限で `questions.json` を読めない。
このフォルダで簡易サーバを立てる。

```
python -m http.server
```

→ http://localhost:8000/ を開く。GitHub Pages 上では普通に動く。
